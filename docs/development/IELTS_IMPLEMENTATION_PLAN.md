# VerbaTrail IELTS 实施路线

本计划将产品目录状态与开发完成状态分开。阶段按依赖排序；不承诺未完成内容或日历日期。每阶段都要求保留可运行成果，并延续 Python 回归。

## 阶段 V0 — IELTS 产品底座与 Reading 首环（本轮）

**交付：** 考试目录 7 项；Academic/GT 持久化目标和目标总分/四科目标；目标水平显示待评估；Alembic 0004 nullable session 快照；Focus 首页四科入口（仅 Reading 可进入）；A/G 各一个原创短阅读题组；领域评价器路由、客观答案判断、真实作答记录，并调用既有诊断/追问/练习/迁移/复习机制；Fake provider 与远程调用安全关闭。

**验收：** 隔离 SQLite 从 0003 升级后，旧 Python 会话仍无考试 variant 且可查询；A/G 模式无法串用 topic；保存目标刷新仍一致；新阅读题来自服务端；对错作答评价正确；错误记录可进入真实诊断，未知领域不落入 Python evaluator；迁移题用不同材料；密钥/标准答案不出现在 DTO。桌面与窄屏人工浏览器验收记录真实情况。

**已知覆盖限制：** 阅读仅有少量原创客观题样例，不覆盖完整矩阵；写作、口语、听力、Band 估分和完整模考未实现。V0 不声称产品达到发布级 IELTS 备考覆盖。

## 阶段 V1 — Reading 内容和题型完整化

**交付：** 通用题组模型（passage/section、题型 schema、答案约束、空位与选项、字数规则）、11 类 Reading 题型、独立答案键评价、A/G 内容隔离、逐题错误与证据映射、审核/版权元数据。

**验收：** A/G 各自矩阵中的 11 种题型均有可执行原创或明确授权内容和正常/错误/边界测试；T/F/NG 与 Y/N/NG 语义独立；多空、同义答案、大小写、拼写和字数规则均由题目版本声明；独立迁移不得复用原材料/同情境；样例原始分不自动推算官方 band。

## 阶段 V2 — 基线评估、语言基础与复习计划

**交付：** 阅读/词汇/语法/表达的小型基线测评；CEFR/技能状态仅在定义过的证据下展示；词汇、语法能力节点与具体尝试关联；对现有 ReviewItem 添加 IELTS 题型过滤/排队策略；可解释周计划建议。

**验收：** 未测显示待评估；每个能力判断能追溯到实际题、作答和规则版本；复习受后端到期状态约束；改变目标不会改写历史；计划建议解释依据和未知项，不把目标分数伪装成当前能力。

## 阶段 V3 — Listening 与媒体基础

**交付：** 6 类听力题型及 multipart answer schema；媒体元数据/权限控制/播放锚点；原创或书面授权音频；练习可重播和未来 mock 的独立播放策略。

**验收：** 每个 Listening 类型至少一套审核内容，Part 1–4 覆盖；逐空答案、字数、数字和替代形式边界测试；媒体断网/解码/权限拒绝能恢复；无音频不允许虚假评分；许可、哈希、来源、保留期限均可追溯；未授权时不向远程 ASR 发送音频。

## 阶段 V4 — Writing Task 1/2

**交付：** Academic 图表/流程/地图 Task 1；GT 书信 Task 1；共通 Task 2；作文草稿版本及多维 Evaluation API；文本锚点和人工评价流程。

**验收：** Task Achievement 与 Task Response 不能混为同一规则；四个评价维度均返回依据或弃评；可保存/恢复长草稿；上传与日志脱敏；AI 反馈标为非官方。未通过预登记专家盲评、一致性与偏差标准前不展示 AI Band。

## 阶段 V5 — Speaking 与语音证据

**交付：** Part 1–3 题组、录音/试听/安全媒体上传、轮次、转写及可选人工纠正、四维 Speaking 反馈。

**验收：** 明确录音同意、用途、期限、供应商及地区；权限拒绝/噪声/静音/超时/断网/删除恢复均覆盖；转写结果不当作 Pronunciation 证据；不可判断维度弃评；模型与成本严格受控并标明非官方。

## 阶段 V6 — 模考、目标计划、档案与发布

**交付：** Academic 原创完整模考、ExamBlueprint/ExamRun 版本与状态、独立计时/提交策略、GT 扩展、四科证据档案、个性化计划和导出/删除。

**验收：** 单套 Academic 模拟结构经最新官方来源复核；Reading 3 passages/40 questions、Writing 两任务、Listening 四部分、Speaking 三部分按考试交付规则实现；中断可按服务端记录恢复；未完成科目不生成 overall；官方分数和 AI/练习估计分开。完整隐私、账号鉴权、可访问性、成本、依赖和版权审查通过后才考虑公开发布。

## 考试版本开放顺序

1. Academic 与 General Training：V0 开放目标及阅读入口，V1 补完整阅读，之后共用 Listening/Speaking、分别完成 Writing，再分别进入 Mock。
2. IELTS for UKVI Academic/General Training：复核官方适用范围和安全考试差异；仅在基础考试模块完整、目录/材料可追溯后开放。不能新增未经官方来源确认的考试题型。
3. Life Skills A1/A2/B1：作为独立产品路径，建立听说任务交互和 Pass/Fail 标准、评估及内容版本；不继承 Band 目标、四科 Overall、Academic/GT 阅读或模考流程。

## 每阶段工程门禁

- 运行后端 pytest、前端测试、typecheck、production build、迁移检查和 `git diff --check`；DB 写入一律在隔离数据库。
- 对每个领域 evaluator 做错误/正确/边界测试，并验证诊断数据来源、假设竞争和证据不足状态。
- HTTP 流程验证幂等、超时后恢复、刷新恢复、越权/错版本拒绝；UI 验证窄屏、键盘操作及错误状态。
- 新内容必须有来源/许可与版本记录；Fake、规则、人工和 Live Model 的输出分别标注。
- Stage 未通过验收不得将首页标记为已开放，不得用 Demo fixture 代替真实内容。
