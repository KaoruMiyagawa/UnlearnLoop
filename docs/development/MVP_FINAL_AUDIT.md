## 4. 数据库、完整性与隐私边界

- `0003` 对已有复习行增加可空关联字段及默认的 `retention_verified=false`、`retention_eligible=false`；迁移测试确认旧的 pending 记录仍 pending，且不会自动变成保持证据。
- 迁移加入调度键、复习会话唯一约束/索引和 Attempt 防重复索引；服务层使用事务、条件更新和刷新后的权威记录应对并发派题/提交。
- 已有 SQLite 配置启用外键；时间按 UTC 处理并在测试中校验时间边界。SQLite 本身写并发能力有限，当前并发测试证明应用保护规则在测试环境下工作，不构成高负载并发容量证明。
- Answer/Attempt、EvidenceLink 和 DecisionEvent 有不可变约束。该设计利于证据审计，但目前没有面向学习者的导出、账户关闭或数据删除 API/UI。直接清除数据库文件是运维手段，不是产品隐私控制；不可变记录还需要明确删除/匿名化政策。
- 当前不是多用户鉴权系统：多个查询接口接受调用者传入的 `learner_id`，该值用于筛选而不是认证身份。默认监听 loopback 适合单用户本机试用；CORS 不构成授权。若绑定到局域网或公网，其他调用方可能指定 learner ID 查询数据，必须先加认证和服务端授权。
- 开发启动时应用会自动将 Alembic 升至 head。虽然迁移在隔离数据库中验证了旧行保留，但启动前没有自动创建并验证 SQLite 备份，也没有面向用户的一键恢复流程。真实数据库在本轮未被迁移。
- `.env` 和数据库不应提交；本次 `git ls-files` 未发现已跟踪 `.env` 或 SQLite 数据库文件。代码默认远程调用关闭，密钥字段不参与配置对象 repr；本轮没有做全面的凭据扫描器检查。

## 5. Agent 与模型适配

- Agent 不是单纯的固定前端步骤：后端规则预评估、历史证据、候选问题和结构化 provider 输出共同参与决策；工具名和参数会经领域校验后才执行。
- 引擎支持竞争假设、支持/反对证据、启发式置信权重、证据不足、预算上限及失败降级；DecisionEvent/ModelCall 记录决策或模型调用元数据。
- FakeModelProvider 是离线模拟，不代表 DeepSeek 的推理质量，也不能证明模型输出在真实部署中的稳定性。UI 的模型状态来自服务端元数据；真实远程请求受配置门控，默认关闭。
- 发现模型失败时，诊断实现会记录失败并进入 `retry_waiting`，保留此前作答和证据。此结论基于代码与 FakeProvider 故障测试，不是实际网络故障注入到 DeepSeek 的结果。
- 若部署真实 provider，仍需单独审查答案发送告知、模型供应商数据保留、预算限额、密钥轮换和生产日志脱敏策略。

### P1 — 发布前处理

#### P1-1：Vite 高危开发依赖公告

- **复现条件：** 使用当前 `package-lock.json` 安装依赖并运行开发服务器/相关 Vite 工具链；完整 `npm audit` 报告 Vite High 与 esbuild Moderate。

- **建议：** 评审受支持的修复版本与 Vite 主版本迁移成本；在兼容升级分支更新 lockfile，并重新跑浏览器、typecheck、build。不要在本审查中强制升级。

#### P1-2：对已有数据库自动迁移前缺少自动备份/恢复保障

- **复现条件：** 使用开发模式启动一个已有旧版 SQLite 文件；FastAPI lifespan 会自动 `upgrade_database(..., head)`，但启动流程不先生成并校验备份。
- **影响：** 迁移虽通过隔离数据库的数据保留测试，真实用户仍缺少可验证的回滚/恢复路径；SQLite 批量表结构迁移失败时恢复依赖手动备份。
- **建议：** 为启动迁移增加“备份到独立文件、校验备份、迁移、失败时保留原件并给出恢复步骤”的流程；用真实副本演练 0002→0003 和恢复。不要对唯一原始数据库直接实验。

#### P1-3：没有产品级学习数据导出与删除控制

- **复现条件：** 用户希望导出或删除个人学习记录；当前 API/UI 没有对应入口，而 Attempt、EvidenceLink、DecisionEvent 具备不可变保护。
- **影响：** 用户无法通过应用自助取得或清除学习数据；与长期维护产品的最低数据控制预期不符。数据库文件手动操作不能替代应用的数据治理。
- **建议：** 在公开发布前定义可导出的结构、删除/匿名化范围、模型调用元数据保留期及不可变审计记录处理方式；实现可确认、可测试的本地用户数据导出和清除流程。
