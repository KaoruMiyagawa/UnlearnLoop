# IELTS 题型覆盖与验收矩阵

状态：规划草案；2026-11-09 对照 IELTS 官方页面。全部 IELTS 行目前**未实现、未验收**。表中的 I1–I7 是 [实施计划](../development/IELTS_IMPLEMENTATION_PLAN.md) 的目标阶段，不表示已交付。题型分类与真实试卷的组合、顺序和出现频率应以所选考试版本为准。

## 1. 统一验收口径

每行除专属标准外，都须满足以下门槛：

1. 使用原创或授权、审校通过且有版本的题组；题干、材料和作答控件适配键盘、桌面及窄屏。未授权内容不得进入产品或仓库。
2. API 返回可公开题面，不暴露私有答案、评分规则或未开放的解释；后端校验作答类型、题目归属和当前可提交状态。提交、断网重试和刷新恢复不得重复生成结果。
3. 答案和评价关联 `learner`、题目版本、材料版本、作答时间、评价来源/规则版本。客观题保存每小题结果及题组聚合；主观题允许 `insufficient_evidence`，不能强制生成数值。
4. 至少包含正常、错误、空答案、边界/格式错误及题库耗尽测试。诊断候选须有来源和不确定性；独立验证使用新材料/情境，间隔复习须有到期后的真实作答。
5. 练习与模考规则隔离；模考不显示标准答案或实时诊断，结束后依权限展示反馈。分数使用非官方标签；验证不足时只展示原始记录。

矩阵“验收标准”是该类型增加到产品后的最低可执行验收，并非宣称真实 IELTS 所有版本只采用某一格式。

## 2. Listening（Academic / General Training 共用）

官方结构：4 部分、每部分 10 题，录音在考试中播放一次，约 30 分钟；练习模式可重听，模考按选定版本的一次播放规则模拟。参考 [IELTS Listening](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-listening)。

| ID | 题型或部分 | 作答形式与专属验收 | 目标阶段 |
| --- | --- | --- | --- |
| L-P1 | 日常双人对话 | 独立题组绑定可播放音频；声音、顺序和题目编号可恢复；录音或音频加载失败不计作答 | I3 |
| L-P2 | 日常单人独白 | 同上；计时与播放策略由题组/模式控制 | I3 |
| L-P3 | 教育/培训场景讨论 | 支持多人说话的一个连续音频和多个题型；不能按说话人数推断答案 | I3 |
| L-P4 | 教育/学术场景独白 | 支持连续音频与多题；练习允许按许可提供片段重听，模考不提供练习控制 | I3 |
| L1 | 单选及多选 | 选项 ID 集合；题目定义要求选择数和判分方式；少选、多选、重复提交均测试 | I3 |
| L2 | 匹配 | 为每个子项选项 ID；按题目规则允许或禁止复用；顺序调整不改变对应关系 | I3 |
| L3 | 平面图/地图/示意图标记 | 使用带替代文本和文字列表的图形资产；选项标签与位置 ID 一一对应，支持键盘操作 | I3 |
| L4 | 表单/笔记/表格/流程图填空 | 每空独立文本或选择项、独立字数/数字上限及接受答案；多空聚合不能覆盖各空结果 | I3 |
| L5 | 句子填空 | 空位 ID 对应答案；按题目配置执行单词/数字上限与拼写规则 | I3 |
| L6 | 简答 | 短文本/数字，多答案按题目要求；超词数与未审核变体不自动判对 | I3 |

音频须有明确版权、媒体格式/长度、校验和及来源。题目答案对应的录音时间戳可供练习后回看，但模考中不提前泄露。

## 3. Academic Reading

官方说明包含三篇材料、40 题、60 分钟。以下按官方类型分别列出；同一类内部的选项、词数和重复使用规则按题目配置。[IELTS Academic Reading](https://www.ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-reading)

| ID | 题型 | 作答形式与专属验收 | 目标阶段 |
| --- | --- | --- | --- |
| R1 | 单选/多选 | 稳定选项 ID；按明确数量、顺序及得分规则判定；结果关联原文证据段落 | I1 单选；I2 多选 |
| R2 | 判断事实 True / False / Not Given | 三值互斥；测试矛盾与文章未提及的区别，不凭外部常识判定 | I1 |
| R3 | 判断作者观点 Yes / No / Not Given | 三值互斥且与 R2 区分；答案与作者观点证据关联 | I2 |
| R4 | 匹配信息 | 条目到段落 ID；按题目说明控制是否重复使用段落 | I2 |
| R5 | 匹配标题 | 段落到标题 ID；禁止题目规则不允许的重复，保留未使用标题 | I2 |
| R6 | 匹配特征 | 陈述到人物/事物等选项；支持按说明重复选择或留空 | I2 |
| R7 | 匹配句尾 | 句首到句尾 ID；按题目规则处理未使用/重复选项 | I2 |
| R8 | 句子填空 | 每空的文本/数字、上限及接受答案按题目配置；测试超限和拼写错误 | I2 |
| R9 | 摘要/笔记/表格/流程图填空 | 同时支持原文取词和词库选择；每空独立规则和证据，明确来源 | I2 |
| R10 | 图示标签填空 | 图像说明有文本替代；每个标签空位与答案 ID 对应 | I2 |
| R11 | 简答 | 逐题短文本/数字；限定词数、拼写及题目审核批准的变体 | I2 |

## 4. General Training 的差异

听力与口语共用上面的能力，不复制一套引擎。General Training 阅读采用生活、工作与一般兴趣材料的三个部分；其题型及组合依题组版本配置。来源：[General Training Reading](https://ielts.org/take-a-test/test-types/ielts-general-training-test/ielts-general-training-format-reading)、[官方样题类型清单](https://www.ielts.org/take-a-test/preparation-resources/sample-test-questions/general-training-test)。

| ID | 能力 | 专属验收 | 目标阶段 |
| --- | --- | --- | --- |
| G-R | General Training 阅读全部相关 R1–R11 交互 | 使用独立 GT 材料/题组和 GT 校准配置；真实题组不要求每次出现全部题型；不得使用 Academic 转换规则冒充 GT 分数 | I7 |
| G-W1 | Task 1 书信：请求、解释等不同交际目的及合适语域 | 书信对象、目的和任务要点与评价证据关联；按 Task Achievement 而非 Task Response 评价；不少于官方要求的 150 词的提示需版本化 | I7 |
| G-W2 | Task 2 议论文 | 独立 GT 题目/评估配置，按任务要求及四维反馈；Task 2 权重按当前官方版本维护 | I7 |

## 5. Academic Writing

官方当前说明：Task 1 描述图表或图示，Task 2 讨论观点、论证或问题；分别建议至少 150、250 词，整场 60 分钟，Task 2 权重为 Task 1 的两倍。[Academic Writing](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-writing)

| ID | 题型 | 作答形式与专属验收 | 目标阶段 |
| --- | --- | --- | --- |
| W1a | Task 1 单图/多图：线图、柱图、饼图、表格及组合 | 长文本；题组附版本化数据与替代文本；事实引用定位回题图，无法读取图或无法核对数值时不得声称已核验任务完成度 | I4 |
| W1b | Task 1 流程、设备、地图/平面图或其他图示 | 图示/步骤的语义描述与原始资产一同版本化；变化及步骤评价能指向题面；图像理解不足时弃评对应事实 | I4 |
| W2 | Task 2 观点、讨论、问题/解决、比较等论证 | 长文本；保留原文，按任务回应、连贯、词汇、语法给对应证据；没有可靠评分时只给观察及改进建议 | I4 |

共通主观评价验收：原文偏移范围能定位，反馈区分错误、改写建议与不确定观察；每维来源/版本独立；短文、离题、空文、模型无效 JSON、超时和重试都可解释处理。词数检查仅作辅助，不把达到字数直接当作合格或固定扣分。

## 6. Speaking

官方口语三部分约 11–14 分钟；Part 2 有准备和连续陈述，Part 3 为更深入讨论。各版本的时间/提示以官方资料复核。[IELTS Speaking](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-speaking)

| ID | 题型 | 作答形式与专属验收 | 目标阶段 |
| --- | --- | --- | --- |
| S1 | Part 1 日常话题问答 | 多轮录音关联轮次；可播放自己的录音，拒绝麦克风权限时显示可重试/退出，不提交空音频 | I5 |
| S2 | Part 2 提示卡、准备和较长陈述 | 区分准备与录音计时；保存题卡版本、录音时长和开始结束状态；中断可恢复或明确标记不完整 | I5 |
| S3 | Part 3 深入讨论 | 保留每轮问题与音频关系；教师预设问题可先支持，动态追问仅在服务端约束和授权模型可用时启用 | I5 |
| S-E | 口语四维反馈 | 音频支持时输出片段时间戳；转写文本不足以判断发音，低质量/无音频时相应维度弃评；口音不应被自动当作错误 | I5 |

## 7. 基础能力与整卷

| ID | 覆盖 | 验收 | 目标阶段 |
| --- | --- | --- | --- |
| F-V | 词义、词族、搭配、同义改写、语境词汇 | 词项关联上下文、误用证据及复习题；不得仅靠中英文单词对判定实际运用能力 | I1 起逐步扩展 |
| F-G | 句子结构、时态、主谓一致、从句、标点等 | 语言规则按任务语境提供证据和修改建议，允许多种正确表达 | I4 起 |
| F-P | 音素、重音、节奏、连读/可理解度练习 | 需真实音频与合适的音频能力，明确参考口音及不确定性；不得以识别正确率代替发音评分 | I5 起 |
| F-E | 观点组织、衔接与口语表达 | 对应文章片段/录音时间段、反馈和新情境验证；不强制单一模板 | I4/I5 起 |
| M-A | Academic 四科完整模拟 | 题组完整性、时间规则、听力播放、提交锁定及中断记录按版本测试；输出须标为非官方模拟 | I6 |
| M-G | General Training 整卷 | 复用听/说，切换 GT 阅读、写作和对应评分配置；与 Academic 历史隔离可筛选 | I7 |
| P-8 | 目标、计划和 Overall 8 进度 | 保存目标和每科证据/计划；样本不足不算预测达标，来源/模型版本发生变化应重新评估可比性 | I6 |

## 8. 内容上线检查

每道题上线前需完成：原创/授权审查 → 题型、答案与变体双人审核 → 可访问性与音图同步检查 → 难度/技能标签审核 → 各错误原因及相反解释审核 → 新情境配对 → 小范围试做和争议修正。题目、素材、答案规则及评价提示必须版本化并可回溯；纠错不覆盖历史作答的题面版本。
