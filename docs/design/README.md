# 设计资料索引

## 当前采用

VerbaTrail 采用 **Clarity** 的信息层级：每屏突出一个当前学习任务，解释任务原因，并明确下一步。Reading 页面保留文章/答题双栏与暖象牙纸阅读底色。

产品主题共用一套 React 组件与业务流程：

- **Premium Academic**：深海蓝、暖纸白，默认主题。
- **Noir & Champagne**：曜黑、香槟金；Reading 长文仍使用暖象牙底色。

最终双主题 HTML、handoff、原型截图位于 [`verbatrail-dual-theme-reference/`](verbatrail-dual-theme-reference/)。React 实际视觉验收证据位于 `../development/theme-visual-acceptance/`。
