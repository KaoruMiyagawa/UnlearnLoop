# 双主题设计参考包

本目录保存最初交接的完整设计原型和原图，来源是 `VerbaTrail_Dual_Theme_Design_Package.zip`。核心文件：

- `VerbaTrail_Dual_Theme_IELTS_Prototype.html`：带实际 HTML/CSS/交互的双主题集成原型。
- `VerbaTrail_Dual_Theme_Design_Handoff.md`：设计决策与 React 集成约束。
- `VerbaTrail_DualTheme_desktop_*.png`、`VerbaTrail_DualTheme_mobile_*.png`：Premium 与 Noir 视觉参考。
- 其他单主题 HTML：历史方向基线，不覆盖最终双主题原型。

原型中的分数、复习任务和作答均为演示数据。正式页面状态以 React + 后端 API 为准；真实浏览器截图请看 `../../development/theme-visual-acceptance/`。
