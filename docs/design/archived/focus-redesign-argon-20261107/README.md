# VerbaTrail 历史方案：Focus 视觉重设计说明与 React 迁移指南

> 归档资料：此方案描述早期 Focus 原型，不覆盖当前已集成的双主题 React 设计。原型位于本目录；当前视觉以 `../../verbatrail-dual-theme-reference/` 和 `../../DESIGN_SYSTEM.md` 为准。

## 一、核心设计转变：从“Agent 调试监控台”回归“专注型自适应学习产品”

针对用户反馈 **“页面眼花缭乱，没有重点”**，本次重设计彻底剥离了原方案 B 中的“控制台感”，确立 **Focus（专注、简洁、现代、克制）** 视觉基准：

1. **三问驱动的信息层级（每一屏只回答三件事）**
   - **我现在需要做什么？**（单主卡片标题 + 高对比度主操作按钮）
   - **为什么系统让我做这件事？**（卡片内嵌温和的 `intent-banner` 简明意图说明）
   - **做完以后会发生什么？**（明确的下一步预期提示，消除未知焦虑）
2. **去除常驻视觉噪音**
   - 移除顶部常驻的六步胶囊进度条、模型 Provider 标签、`DecisionEvent` 原始日志流与演练控制栏。
   - 移除深色左侧常驻导航栏与右侧常驻证据侧栏，改为 **轻量毛玻璃顶部导航 + `720px` 居中单列阅读与作答画布**。
3. **渐进式披露（Progressive Disclosure）**
   - **Agent 诊断**：默认仅呈现一句友好、直白的核心卡点解释与下一步练习入口；仅当学习者点击“展开查看候选错误原因、正反证据与不确定性说明”时，才平滑展开候选原因对比、正反证据链与启发式判断说明（明确标注并非统计概率）。
   - **参考材料**：默认收起为一行安静的提示按钮，按需展开，不打断题目阅读与代码作答路径。

## 三、与现有 React 组件的迁移建议（待评审通过后实施）

评审通过后，无需改动后端或 `frontend/src/api/`，只需对现有 React 视图层进行减法重构：

1. **`AppShell.tsx` & `tokens.css`**
   - 将双栏 `.wb-shell`（深色左轨 + 顶部六步条）替换为轻量顶部导航 `.top-nav` 与 `max-width: 720px` 居中容器 `.stage-container`。
   - 收敛色彩变量：仅保留 `#F8F9FA` 画布底色、`#FFFFFF` 焦点卡片、`#111827` 主文字与 `#1D4ED8` 单一主行动色。
2. **`App.tsx`（首页视图）**
   - 移除 4 张 KPI 统计卡片网格与常驻右侧检视轨。
   - 以单张 **“继续学习”焦点卡片** 作为视觉中心，下方以克制的单列列表展示待复习项与近期掌握进展。
3. **`LearningWorkspacePlaceholder.tsx`（学习工作区）**
   - 移除分栏网格与底部 `DecisionEvent` 审计表，将“意图说明 → 题目与代码 → 按需折叠参考材料 → 作答输入框 → 单一主按钮”整合在单张稳态焦点卡片中。
4. **`DiagnosisWorkspacePlaceholder.tsx` & `DiagnosticInspectorRail.tsx`（Agent 诊断）**
   - 合并为单列渐进式披露组件：默认态展示一句话诊断结论与“开始针对性练习”按钮；折叠抽屉内展示竞争假设、正反证据与启发式工作判断说明。
5. **`ReviewWorkspacePlaceholder.tsx` & `ProfileWorkspacePlaceholder.tsx`（迁移验证与学习档案）**
   - 迁移验证页仅聚焦独立新情境题目作答，用温和的一句话提示解释“为何换新题防记忆干扰”；学习档案页改为认知变化轨迹叙事列表，弱化生硬枚举码展示。
