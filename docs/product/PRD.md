# VerbaTrail 产品需求概要

当前产品范围摘要，更新于 2026-11-13。Matching Headings 的工程验收及限制以 [IELTS-2B.1 Phase 6.2 最终复验](../development/IELTS_2B1_PHASE6_2_ACCEPTANCE.md)为准。

## 产品定位

VerbaTrail 是以学习者为中心、由自适应学习 Agent 驱动的语言学习系统。它长期希望帮助学习者建立理解、沟通和真实运用语言的能力。**IELTS Overall Band 8.0 是首个目标场景，不是成绩预测或保证。**

## 产品信息架构

VerbaTrail 的顶层入口为 **Learn（学习） / Discover（发现） / Adapt（自适应）**。Learn 包含 **Listening（听力） / Speaking（口语） / Reading（阅读） / Writing（写作）** 四个一级板块。Discover 负责有合法来源的外部学习资源，Adapt 负责个性化规划与决策，两者当前均为规划中。

词汇、语法、Error DNA、迁移、复习、学习历史与能力评估是跨技能共享能力。技能入口复用共享的学习者目标、能力证据和学习历史服务。

## 用户价值

- 从学习目标出发，并把“目标”与“当前已验证能力”分开显示。
- 依据真实作答和可追踪证据安排下一步活动。
- 通过阅读、听力、词汇、语法等输入发展理解，通过写作、口语和交流发展表达。
- 使用反馈帮助学习者理解错误、验证新情境迁移，并在适当时间复习。
- 清楚标识规则评价、模拟模型输出、人工评价及尚未知晓的内容。

## 目标体验流程

```mermaid
flowchart LR
    A[目标与学习者档案] --> B[初始/持续评估]
    B --> C[个性化学习计划]
    C --> D[输入与输出活动]
    D --> E[服务端评价与反馈]
    E --> F[候选错误模式 / Error DNA]
    F --> G[针对性活动与新情境迁移]
    G --> H[间隔复习与能力证据]
    H --> C
```

这是产品目标流程；实际步骤应由服务端能力和证据决定。不得为填满流程伪造评估、诊断、迁移、保持或进度结果。

## 产品规则

1. 当前能力证据必须可追溯到具体任务、作答、内容版本和评价来源；未评估显示未知。
2. 单次错误只能产生经内容规则支持的候选解释，不能直接确认长期弱点。
3. 练习正确不等于陌生语境迁移；迁移通过不等于延迟保持；一次延迟复习通过也不代表永久掌握。
4. 对旧历史保持可追溯。发现内容或评分缺陷时，保留原始记录并增加有效性处理和重算路径，不能悄悄改写历史。
5. 只有在内容、版权、隐私、模型质量和工程验收满足要求后，才开放新技能或真实模型能力。
6. IELTS 目标分数不可伪装成系统预测分数或官方成绩。

## 非功能及信任边界

- 当前运行配置面向可信的本地单用户开发；`learner_id` 只是筛选参数，不是认证或授权。
- 远程模型调用默认关闭，FakeModelProvider 只用于离线流程模拟；不得将其称为真实 AI 个性化诊断成功。
- 内容需记录版本、原创/授权信息和可核查答案依据。现有内容只经过内部检查，未通过外部专家审校。
- 本地数据库迁移前需备份并验证恢复。生产级数据保留、导出、删除和账号安全尚待设计。
